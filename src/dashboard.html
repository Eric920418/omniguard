Prompt injection is not solved. The inbound lock checks known phrases and, when GMI_API_KEY is configured, AI semantics. AI errors or review decisions stop forwarding. The outbound lock is blast-radius control: a plaintext Stripe key in the body is cut off before upstream. The content check uses the Public Suffix List. Without a vision key, the visual signal is a local color heuristic labeled palette, not a vision model. A real checkout screenshot is mostly white and will not trip that heuristic. Content inspection is advisory: the agent must call /v1/guard/inspect for each destination and redirect, and must stop on block, review, or errors. This gateway cannot control navigation outside these routes.
